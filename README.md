# HealthCare — Pulse Care

Healthcare PWA with offline local storage and device-scoped MongoDB persistence.

## Stack
- HTML/CSS/JavaScript PWA
- Node.js + Express API
- MongoDB Atlas
- Render

## Data
Database: healthcare
Collection: device_states
Fields: deviceId, state, updatedAt

## Local run
Set MONGODB_URI and MONGODB_DB=healthcare, then run npm install && npm start.
